# Assets Directory

This directory contains the app's assets including icons and images.

## Required Assets

Before building the app for production, you'll need to add the following image files:

### App Icons
- **icon.png** (1024x1024px) - Main app icon
- **adaptive-icon.png** (1024x1024px) - Android adaptive icon
- **favicon.png** (48x48px or larger) - Web favicon

### Splash Screen
- **splash.png** (2048x2048px recommended) - Splash screen shown while app loads

## Creating Icons

You can create icons using:
1. Design tools like Figma, Sketch, or Adobe Illustrator
2. Online icon generators
3. The Expo icon generator: https://docs.expo.dev/guides/app-icons/

## Icon Guidelines

- Use simple, recognizable designs
- Include baby-related imagery (baby bottle, pacifier, baby face, etc.)
- Use the app's color scheme: pink (#FF6B9D), teal (#4ECDC4), purple (#A78BFA)
- Ensure icons work well at small sizes
- Test on both light and dark backgrounds
