# Fonts

The app uses the Fredoka font family for a fun, friendly look.

To add the fonts:
1. Download Fredoka font from Google Fonts: https://fonts.google.com/specimen/Fredoka
2. Add the following files to this directory:
   - Fredoka-Regular.ttf
   - Fredoka-Bold.ttf

Alternatively, the app will fallback to system fonts if these are not available.
